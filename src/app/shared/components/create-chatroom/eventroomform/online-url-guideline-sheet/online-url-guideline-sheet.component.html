Guidelines for online event url

Use the following guidelines to best use the online event url:

What are online events

Online events are the events that can be performed via web video conferencing tools. There are plenty of video conferencing tools out there like Zoom, Hangout, Skype etc.

Recommended online platforms

Recommended tools are those where joining the conference is easier and can handle the number of expected participants joining your event online.

Link to online event

Make sure that you provide the video conferencing urls and not the event description page from other platforms.
