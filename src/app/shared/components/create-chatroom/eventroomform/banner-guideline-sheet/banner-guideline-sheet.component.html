Guidelines for image files

Use the following guidelines to get the highest quality event image:

Dimensions

Find at least a 2160 x 1080px (2:1 ratio) image.

File Type

Pictures with file types JPEG, BMP, PNG, or GIF work best.

File Size

Use a photo that's not larger than 10MB.

General

Avoid images that have a lot of text, logos, and fliers.
